OBS Tab Player - install
========================

Easiest: run obs-tab-player-<version>-windows-x64-setup.exe.

From the ZIP: extract it, then double-click Install.cmd. No administrator rights
are needed; it copies the plugin into C:\ProgramData\obs-studio\plugins.

Then start OBS. The "Tab Player" panel shows two buttons:
  1. Choose your tabs folder
  2. Add Tab Player to this scene
Pick a tab, press Play. Done. No tabs yet? Six practice tabs are in the
folder C:\ProgramData\obs-studio\plugins\obs-tab-player\demo-tabs (with the ZIP:
the demo-tabs folder next to Install.cmd).

The Audio Mixer gets two faders: "Tab Player" (the guitar) and
"Tab Player Metronome" (the clicks), so each has its own volume and tracks.

Requires OBS Studio 30 or newer on Windows 10/11 (64-bit).
Uninstall: Uninstall.cmd, or "Apps > Installed apps" when installed with the setup.
Step-by-step guide with pictures: https://bask209.github.io/obs-tab-player/start.html
