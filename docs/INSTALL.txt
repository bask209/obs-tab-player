OBS Tab Player - quick setup (about one minute)
================================================

1. Extract this folder somewhere permanent, for example Documents\OBS Tab Player.
2. In OBS: Tools > Scripts > "+" > choose tab-player.lua from this folder.
3. In the script settings on the right:
     - Tab folder: pick the folder with your .gp/.gpx/.gp3/.gp4/.gp5 files
       (or the demo-tabs folder to try it out).
     - Click "Add overlay to current scene".
4. Add the controls: Docks > Custom Browser Docks...
     Dock Name: Tab Player
     URL:       http://127.0.0.1:8737/dock.html
   Click Apply. Dock it wherever you like.

Pick a tab in the dock, press play. The audio goes through the "Tab Player"
source in OBS's audio mixer, so it is in your recordings and streams.

Hotkeys: Settings > Hotkeys, search for "Tab Player".

More help: https://bask209.github.io/obs-tab-player/
