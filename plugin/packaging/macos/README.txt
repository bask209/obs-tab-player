OBS Tab Player - install on macOS
=================================

For OBS Studio 30 or newer on macOS 11 or newer (Apple silicon and Intel).

1. Quit OBS.
2. Double-click Install.command.
   macOS may say it cannot verify the developer: Control-click Install.command,
   choose Open, then Open again. The plugin is free and open source but not
   signed with a paid Apple developer certificate.
   It copies the plugin into ~/Library/Application Support/obs-studio/plugins
   (no administrator password needed).
3. Start OBS. The "Tab Player" panel shows two buttons:
     1. Choose your tabs folder
     2. Add Tab Player to this scene
   Pick a tab, press Play. Demo tabs are in the demo-tabs folder here.

The Audio Mixer gets two faders: "Tab Player" (the guitar) and
"Tab Player Metronome" (the clicks).

Uninstall: double-click Uninstall.command.
